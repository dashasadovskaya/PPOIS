# Лабораторная работа №4. Вариант 9

## Задание 1. Сортировка
- **Library sort** — gapped insertion sort. Вставляет элементы в массив
  с зазорами, при заполнении расширяет и расставляет равномерно.
- **Spread sort** — bucket-based. Разбивает по диапазону значений на K
  корзин, сортирует каждую, сливает.

Обе функции обобщённые (template) и работают:
- с массивами (`T*`, размер);
- с `std::vector<T>`;
- с любым `T`, поддерживающим `operator<`.

Для демонстрации создан класс `Student` (имя, оценка).

## Задание 2. Граф (вариант 2.1.9)
**Неориентированный граф (ортогональный список смежности).**

Обобщённый шаблонный класс `Graph<T>`, где `T` — тип данных в вершине.

### Методы
| Метод | Что делает |
|---|---|
| `addVertex(data)` | Добавить вершину |
| `hasVertex(id)` | Проверить наличие |
| `removeVertex(id)` | Удалить вершину (и все её рёбра) |
| `addEdge(a, b)` | Добавить ребро |
| `hasEdge(a, b)` | Проверить наличие ребра |
| `removeEdge(a, b)` | Удалить ребро |
| `degree(id)` | Степень вершины |
| `vertexCount()` | Количество вершин |
| `edgeCount()` | Количество рёбер |
| `empty()` / `clear()` | Пустота / очистка |
| `vertexData(id)` | Данные вершины |

### Итераторы
- `VertexIterator` — двунаправленный итератор по вершинам.
- `ConstVertexIterator` — константный итератор по вершинам.
- `EdgeIterator` — двунаправленный итератор по рёбрам.

### Исключения
- `GraphException` — базовое
- `VertexNotFoundException`
- `EdgeNotFoundException`
- `DuplicateException`
